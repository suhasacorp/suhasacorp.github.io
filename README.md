# suhasacorp.github.io

Company website for Suhasa Corp, a Toronto-based AI, Data, and ML software consultancy covering:

- AI consulting & AI engineering
- Machine learning model development & MLOps
- Python backend engineering
- AWS cloud architecture
- Data and business analytics
- Financial analytics

## Before publishing

Replace all placeholders:

- `Principal AI Engineer` (add real name/title if desired)
- `Business Analytics Consultant`
- `hello@suhasacorp.example`
- `[SUHASA CORP EMAIL]`
- `LinkedIn profile — add URL`
- `GitHub profile — add URL`
- Case-study links
- Booking link
- Exact certification names

Do not publish unverified client names, metrics, credentials, or technology claims.

## GitHub Pages

For a user/organization site, the repository must be named `<owner>.github.io` — e.g. `suhasacorp.github.io`. GitHub Pages can publish static HTML/CSS/JavaScript directly from the repository or via GitHub Actions.

See GitHub's documentation:
https://docs.github.com/en/pages/quickstart
